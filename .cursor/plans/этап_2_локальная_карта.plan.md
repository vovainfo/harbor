# Этап 2. Карта подхода судов с локальным кешем (V2)

## 1. Цель

Карта подхода судов к порту Владивосток, у которой **онлайн из внешней сети приходят только позиции судов**. Всё картографическое (подложка, подписи, значки, морская обстановка) хранится в информационной базе и при открытии формы целиком переносится на клиент.

Требования пользователя (17.10.2026):

1. Все объекты первого этапа переименовать с суффиксом **V1**.
2. Объекты второго этапа создаются с суффиксом **V2**.
3. Суть этапа:
   - онлайн получаем только данные о положении судов;
   - реализовать **загрузку картографических данных**: данные получает **клиент** и отправляет на **сервер**;
   - доступа в интернет к картографическим данным **с сервера нет**, **с клиента есть**; доступ к API позиций судов с сервера есть;
   - где есть выбор — данные **векторные**, а не растровые;
   - **вся карта кешируется на клиенте при открытии формы**, дальше к серверу не обращаемся;
   - исключения: координаты судов (регламент на сервере запрашивает внешний API, обработчик ожидания формы забирает их с сервера) и форма, открываемая по клику на объект (за дополнительной информацией к серверу можно).

## 4. Шаг 0 — проверки до кода

1. **Сжатие тайлов OpenFreeMap.** Запросить `.pbf` с `Accept-Encoding: gzip` и без. Нужно, чтобы клиент 1С (`HTTPСоединение`) получал **распакованный** protobuf (MapLibre 1.15 не распаковывает gzip сам, а в V8WebKit нет `DecompressionStream`). Проверить:
   - что сервер отдаёт без сжатия, если клиент не заявляет `gzip`;
   - что `HTTPСоединение` тонкого клиента делает с ответом `Content-Encoding: gzip` (первые байты `1f 8b` — сжато).
   Если распаковку обойти нельзя — загрузчик не шлёт `Accept-Encoding` и проверяет первые байты каждого тайла.
2. **Морские объекты OSM.** Запрос Overpass `[out:json][timeout:120];(nwr["seamark:type"](south,west,north,east););out geom;` (без `[out:json]` Overpass отвечает XML) для ближней зоны и района: число объектов по типам (`anchorage`, `fairway`, `separation_*`, `buoy_*`, `beacon_*`, `light_*`, `harbour`, `restricted_area`…), доля с `name:ru`, объём ответа. Рабочие адреса Overpass (`overpass-api.de` и зеркала) проверить с клиентской машины. 17.10.2026 проверка не выполнена: исходящий HTTPS с машины разработчика шёл через `localhost:10808`, прокси перестал отвечать.
   - Если объектов достаточно (якорные стоянки, фарватеры, буи у Владивостока) — вектор.
   - Если мало — запасной вариант: растр OpenSeaMap z9–16 в том же кеше, только непустые тайлы (пустой — общий прозрачный), источник `maxzoom: 16`.
3. **Объём кеша выбранного района** (`tools/estimate_map_cache.py`): итог по тайлам, шрифтам, спрайтам, морской обстановке → число пакетов по 1,5 МБ.
4. **Диагностика V2 в тонком клиенте** (локально и через RDP), см. раздел 10:
   - передача строк 0,5 / 1 / 2 / 4 МБ из 1С в атрибут моста и обратно: время, успех — отсюда размер пакета;
   - `atob` и раскладка base64 → `ArrayBuffer`: время на 10 МБ;
   - `addProtocol` в V8WebKit на тестовом наборе (карта из словаря без сети);
   - доступность и постоянство `localStorage` / `IndexedDB` у страницы, собранной строкой (если сохраняются между сеансами — кеш на клиенте можно переиспользовать, см. п. 9.6).

Результаты шага 0 записываются в этот план до начала кода.

### 4.1. Результаты шага 0 (17.10.2026, запросы напрямую с машины разработчика, без прокси)

**1. Сжатие — решено.**

- OpenFreeMap отдаёт тайл без сжатия, если клиент не заявляет `gzip`: без заголовка и с `Accept-Encoding: identity` — `Content-Encoding` нет, 160 214 байт, начало `1a 92` (protobuf). С `Accept-Encoding: gzip` — `Content-Encoding: gzip`, 102 354 байта, начало `1f 8b`.
- С `Accept-Encoding: identity` без сжатия приходят все виды ресурсов: тайл, стиль (`7b 22`), шрифт `Noto Sans Regular/1024-1279` (125 222 байта), спрайт `ofm@2x.png` (`89 50`), ответ Overpass (`7b 0a`).
- Встроенный `HTTPСоединение` 1С gzip **не распаковывает**: `ПолучитьТелоКакДвоичныеДанные()` возвращает сжатые байты. Сам он `gzip` не заявляет — в описанных случаях заголовок выставляли вручную ([Инфостарт: чтение сжатого ответа](https://infostart.ru/public/844121/), [форум: API МойСклад](https://forum.infostart.ru/forum9/topic319622/)). Упоминание о нативной распаковке в 8.3.26 встречается только в сообщении на форуме и официально не подтверждено.
- **Решение:** загрузчик явно ставит `Accept-Encoding: identity` и проверяет первые байты каждого ответа; `1f 8b` → отказ загрузки с понятной ошибкой. Распаковка в 1С или JS не нужна.

### 7.1. Состав

Ключи ресурсов (они же адреса `harbor://<ключ>` на клиенте):

| Ключ | Что | Источник |
|---|---|---|
| `style/positron`, `style/liberty` | Стили (JSON) | `https://tiles.openfreemap.org/styles/<имя>` |
| `tilejson` | TileJSON (адрес тайлов со сборкой, `minzoom`/`maxzoom`, слои); `maxzoom` **14 не меняется** — MapLibre растягивает z14 и не запрашивает z15+, которых в кеше нет | `https://tiles.openfreemap.org/planet` |

Диапазоны — **шесть**, как в замере: `0-255`, `256-511`, `1024-1279` (кириллица), `8192-8447`, `8448-8703` (в том числе `№`), `9472-9727` | `https://tiles.openfreemap.org/fonts/<fontstack>/<range>.pbf` (в HTTP-запросе загрузчика пробелы кодируются `%20`, в ключе — нет) |

Правило: **ключ = адрес, который запросит MapLibre 1.15.3, без `harbor://`** (п. 9.3–9.4). Промах по ключу шрифта даёт пустые подписи, по спрайту — ошибку загрузки стиля. Ключи `style/*` и `seamark/overpass` карта не запрашивает: стиль передаётся объектом, ответ Overpass разбирает свой код.

Из стилей при выдаче удаляется источник `ne2_shaded` (растр Natural Earth, `maxzoom` 6, адрес в `tiles`) и слои на нём (`natural_earth` у Liberty): правило переписывания `sources.*.url` его не трогает, и на зуме ниже 7 карта пошла бы в интернет. Для акватории он не нужен.

### 7.2. Параметры набора

`КартографическиеДанныеV2.ПараметрыНабора()` — единственное место: bbox кеша `[lonMin, latMin, lonMax, latMax]` (из `ПолучениеДанныхAISV2.ПараметрыРайона()`), масштабы `11–14` (нижний — `minZoom` карты, п. 9.8), стили, диапазоны шрифтов, адреса источников, Overpass-запрос, целевой размер пакета.

**Overpass-запрос** — `[out:json][timeout:120];(nwr["seamark:type"](south,west,north,east););out geom;`. Порядок bbox у Overpass — `юг,запад,север,восток` (`latMin,lonMin,latMax,lonMax`), как у Open Waters; это исключение из правила «`[lon, lat]` везде» (AGENTS.md), и, как у Open Waters, строка запроса собирается в одном месте рядом с адресом из bbox `[lonMin, latMin, lonMax, latMax]`. Адреса Overpass — список, первым `https://z.overpass-api.de/api/interpreter` (п. 4.1).

**bbox** (решение ревью 18.10.2026) — «акватория подходов» 131.55–132.35° в. д., 42.80–43.25° с. ш., ≈ 65 × 50 км (Золотой Рог, Босфор Восточный, Амурский и Уссурийский заливы у Владивостока, о. Русский); `maxBounds` карты V2 = bbox набора с небольшим запасом, чтобы пользователь не уводил карту туда, где тайлов нет. Объём по замеру шага 0 — ≈ 12,5 МБ, 17 МБ в base64 (п. 4.1).

### 7.3. Формат пакета

```json
{"set":"<uuid набора>","n":7,"items":[{"k":"tiles/14/14194/6013","b":"<base64>"},{"k":"glyphs/Noto Sans Regular/0-255.pbf","b":"<base64>"}]}
```

- Ресурсы JSON (стили, TileJSON, Overpass) тоже кладутся base64 от UTF-8 байтов — один путь раскладки на клиенте.
- Размер пакета — до ≈ 1,5 МБ строки (уточняется шагом 0 по допустимому размеру строки в мосте). Ресурс больше лимита — отдельным пакетом.

## 8. Загрузка набора (форма `ЗагрузкаКарты`)

Открывается из формы карты V2 (кнопка «Загрузка картографических данных», только администратору). Работает в **тонком клиенте**; в веб-клиенте — сообщение «Загрузка доступна только в тонком клиенте».

Порядок:

1. **Сервер** `КартографическиеДанныеV2.НачатьНабор()` — проверка права; **все существующие наборы `loading` переводятся в `failed`, их пакеты удаляются** (брошенная загрузка — закрытый клиент, обрыв сеанса — иначе осталась бы навсегда; параллельно грузит один администратор, второго набора `loading` по построению не бывает); новая запись `НаборыКартыV2` со статусом `loading`; возвращает идентификатор набора и параметры.
2. **Клиент** скачивает список источников: TileJSON, стили; из стилей — адреса спрайта и множество `text-font`; строит список ключей: стили, TileJSON, спрайт 1x/2x, шрифты (начертания × диапазоны), тайлы (перебор `z/x/y` по bbox и масштабам), Overpass.
3. **Клиент** скачивает ресурсы **одной `Асинх`-процедурой с циклом**: `Ответ = Ждать Соединение.ПолучитьАсинх(Запрос)`, строго по одному запросу; каждое `Ждать` отпускает интерфейс, прогресс обновляется, флаг «Отменить» проверяется на каждой итерации. Обработчик ожидания для шагов не нужен.
   - Соединение — как `ЗапроситьСудаOpenWaters` V1: `Новый HTTPСоединение(Хост, 443, , , Новый ИнтернетПрокси(Истина), Таймаут, Новый ЗащищенноеСоединениеOpenSSL)`; **одно соединение на хост** на весь набор (`tiles.openfreemap.org`, адрес Overpass).
   - Заголовки: **`Accept-Encoding: identity`**; первые байты тела `1f 8b` → отказ загрузки (п. 4.1).
   - Таймаут: тайлы, стили, шрифты, спрайт — **30 с**; Overpass — **120 с** и `[timeout:120]` в запросе (замер: 38–42 с на ближнюю зону и район, bbox кеша больше ближней зоны).
   - Overpass: `ПолучитьАсинх` по адресу `/api/interpreter?data=<КодироватьСтроку(Запрос, СпособКодированияСтроки.КодировкаURL)>` (запрос из п. 7.2, ≈ 200 символов); Overpass принимает `data=` и в GET.
   - В набор попадает **только ответ 200**, в том числе маленький protobuf — это данные. **204 и тело нулевой длины** — пропуск ключа. **301/302** — отказ ресурса (соединение по редиректу само не идёт, тело редиректа — не тайл). **404 у тайла или диапазона шрифта** — пропуск ключа со счётчиком в итоге и в журнале (у OpenFreeMap это статические файлы; например, стека из двух шрифтов на сервере нет — час загрузки из-за одного файла не теряется). **404 у стиля, TileJSON, спрайта, а также 5xx и 429** — два повтора, затем отказ загрузки.
4. **Клиент** копит элементы `{k, b}`: `b` — **`ПолучитьBase64СтрокуИзДвоичныхДанных(Тело)` с удалением `Символы.ВК` и `Символы.ПС`** (`Base64Строка` вставляет перевод строки каждые 76 символов; отсутствие переводов строк проверяет диагностика V2). Текст пакета собирается **`ЗаписьJSON`** по структуре `{set, n, items}` (доступна в тонком клиенте), не конкатенацией. При достижении целевого размера вызывает **сервер** `ЗаписатьПакет(Набор, Номер, ТекстПакета, КоличествоРесурсов)` (`&НаСервереБезКонтекста`, проверка права, набор должен быть `loading`). Запись **идемпотентна**: запись `(Набор, Номер)` перезаписывается, повтор после обрыва вызова не плодит второй пакет.
5. **Сервер** `ЗавершитьНабор(Набор, Манифест)`: сверяет число пакетов и ресурсов с манифестом клиента; **одна транзакция с управляемой блокировкой** регистров `НаборыКартыV2` и `ПакетыКартыV2`; активируется только набор в статусе `loading`; текущий `active` → `previous`, новый → `active`, прежний `previous` и все `failed` старше суток удаляются вместе с пакетами. **Пакеты `previous` хранятся** до следующей активации, потому что форма пользователя, открытая во время смены набора, дочитывает пакеты старого набора по его идентификатору; удалять их сразу нельзя.
6. Ошибка или отмена → `ОтменитьНабор(Набор)`: статус `failed`, пакеты удаляются. Активный набор не меняется.
7. **Закрытие формы во время загрузки.** `ПередЗакрытием`: если загрузка идёт — `Отказ = Истина`, выставить флаг отмены; цикл на очередной итерации выходит, вызывает `ОтменитьНабор` и закрывает форму сам. Иначе `Асинх`-процедура продолжит работать на закрытой форме и упадёт на обращении к элементам.

Интерфейс формы: параметры набора (только просмотр), этап, «скачано N из M ресурсов, X МБ», «передано пакетов K», текущий ресурс, кнопки «Начать» и «Отменить», итог (сколько ресурсов, объём, время). Журнал регистрации: событие `Подход судов.Загрузка карты V2`, начало, итог, ошибки (без тел ответов).

Бережность к источникам: строго последовательные запросы; OpenFreeMap и Overpass — бесплатные сервисы. Полная загрузка района из шага 0 — тысячи запросов, порядка 5–15 минут.

## 9. Карта V2 (форма `Форма`)

### 9.1. Открытие формы

1. `ПриСозданииНаСервере`: собрать HTML (макеты + MapLibre + начальные данные: параметры района, манифест активного набора — идентификатор, число пакетов, bbox; последний снимок судов). **Картографических данных в HTML нет.**
2. Страница показывает индикатор «Загрузка карты: 0 %» и шлёт событие `ready`, **как только мост готов — до создания карты**. В V1 `ready` уходит из `style.load`; если так оставить, клиент ждёт `ready`, чтобы начать пакеты, а страница ждёт пакеты, чтобы создать карту.
3. Клиент по `ready` переносит пакеты **шагами, не циклом**: каждый шаг — серверный вызов `ПакетыКарты(Набор, С, По)` (`&НаСервереБезКонтекста`, 2–3 пакета, ≤ ≈ 4 МБ) и команды `{"op":"addCachePackage","package":<строка пакета>}` (строка вставляется конкатенацией, без разбора на клиенте 1С); следующий шаг — `ПодключитьОбработчикОжидания(…, 0.1, Истина)`, как `ОтправитьОжидающуюКоманду` в V1. Синхронный цикл не дал бы HTML-полю перерисовать индикатор и заморозил бы опрос и кнопки формы. Закрытие формы останавливает перенос: шаг начинается с проверки клиентского флага.
4. После последнего пакета — команда `{"op":"startMap"}`: JS создаёт карту из кеша.
   - Опрос позиций (30 с) включается при открытии формы и может принести `updateVessels` **до** `startMap`: снимок до создания карты только запоминается и применяется в `startMap` (в V1 `applySnapshot` сразу обращается к `map.getSource`).
5. Если активного набора нет — сообщение «Картографические данные не загружены. Администратор: Загрузка картографических данных» и карта на запасном пустом стиле с судами (как V1 без подложки).

Ограничение по требованию: **после шага 4 к серверу обращаются только** опрос позиций судов (раз в 30 с) и форма `КарточкаСудна`.

### 9.2. Кеш в JS

- `cache = {}` — ключ → `ArrayBuffer`. Команда `addCachePackage` собрана конкатенацией, как `updateVessels`: после **одного** `JSON.parse` команды поле `package` — уже объект, второго разбора нет. `atob` — по полю `b` каждого элемента → `Uint8Array.buffer`; считает принятые пакеты, обновляет индикатор.
- `data-ack` выставляется **после** раскладки пакета в словарь: `ОтправитьВМостКарты` читает `data-ack` сразу после `click()` и следующим вызовом затирает `data-payload`.
- После `JSON.parse` JS **очищает `data-payload`**: иначе последняя строка в 1,5 МБ живёт в атрибуте DOM до конца сеанса; 1С после `click()` читает только `data-ack` и `data-error`.
- Память: объём набора ×1 (сырые байты) плюс собственный кеш MapLibre. Для 15–25 МБ — допустимо; цифры подтверждаются шагом 0.

### 9.3. Протокол `harbor://`

`maplibregl.addProtocol('harbor', function (params, callback) {…})`:

- ключ = адрес без `harbor://` (правило п. 7.1);
- `params.type === 'json'` → `JSON.parse(TextDecoder('utf-8').decode(buffer))` → `callback(null, объект)`;
- иначе → `callback(null, buffer.slice(0))` — копия, потому что буфер из словаря библиотека передаёт в worker;
- ресурса нет: для тайлов и шрифтов — пустой `ArrayBuffer` (тайл без объектов; диапазон шрифта без глифов), **никогда не `Error`**: ошибка без `sourceId` в логике V1 сбрасывает стиль на пустой, а кромка широкого окна на zoom 11 может выходить за bbox; для стиля, TileJSON и спрайта — `callback(new Error('нет в кеше: ' + ключ))`;
- обработчик **возвращает `{cancel: function () {}}`** — без этого `abortTile` и смена стиля вызывают `cancel` у `undefined`;
- запросов в сеть обработчик **не делает**.

### 9.4. Переписывание адресов

Перед `new maplibregl.Map` JS берёт стиль из кеша и заменяет:

- удаляет источник `ne2_shaded` и все слои на нём (п. 7.1);
- `sources.openmaptiles.url` (TileJSON OpenFreeMap) → `harbor://tilejson`;
- в TileJSON при выдаче: `tiles` → `['harbor://tiles/{z}/{x}/{y}']`, **`minzoom` → 11** (нижний масштаб набора), `maxzoom` остаётся 14, **`bounds` → bbox набора**. По бандлу 1.15.3: при `minzoom` 0 тайл в состоянии ошибки заставляет библиотеку запрашивать родителей до z1; `bounds` отсекает тайлы вне набора до запроса — кромка окна за bbox остаётся цветом фона. Пустой `ArrayBuffer` на промах (п. 9.3) остаётся запасным путём;
- `glyphs` → `harbor://glyphs/{fontstack}/{range}.pbf`;
- `sprite` → `harbor://sprite/ofm` (последний сегмент исходного адреса; библиотека сама допишет `.json`/`.png` и `@2x`).

Так же при смене Positron ↔ Liberty (`setStyle(объект, { diff: false })` + `ensureOwnLayers()` на `style.load`, как в V1). Подмена подписей на `name:ru` — как в V1.

### 9.5. Векторная морская обстановка

- JS превращает `seamark/overpass` в GeoJSON: узлы → Point, замкнутые пути с площадными типами (`anchorage`, `restricted_area`, `harbour`, `seaplane_landing_area`…) → Polygon, остальные пути → LineString; отношения `multipolygon` — внешние кольца. Свойства: `seamark:type`, `seamark:name`/`name:ru`/`name`, цвета буёв и знаков.
- Слои из макета `СтильМорскойОбстановки` (вставляется в начальные данные): районы — полупрозрачная заливка и контур, фарватеры и зоны разделения — пунктир, буи и знаки — круги цвета по `seamark:*:colour`, огни — маленькие звёзды-кружки, подписи — `coalesce(name:ru, seamark:name, name)`. Источник GeoJSON и слои добавляет `ensureOwnLayers()` — под первой подписью подложки, под судами (как seamark в V1). Константа `SEAMARK_TILES` (`tiles.openseamap.org`) и растровый источник V1 в страницу V2 **не переносятся**.

### 9.6. Повторные открытия

Базово каждое открытие формы заново переносит набор (секунды в локальной сети). Если шаг 0 покажет постоянное хранилище страницы (`IndexedDB` или `localStorage` достаточного объёма между сеансами) — JS хранит набор с идентификатором и при совпадении идентификатора пропускает перенос (форма спрашивает у страницы идентификатор сохранённого набора до запроса пакетов). Иначе — без оптимизации.

### 9.7. Суда

Как V1 (контракт судна, иконки по группам и возрасту, корпуса с z14, подписи, плашка устаревания, строка состояния на сервере, опрос раз в 30 с, `updateVessels`, мосты). Отличие — клик:

- JS выделяет судно (слои `vessel-selected`, `vessel-hulls-selected`) и открывает popup, как в V1 (поля контракта из снимка в памяти, `textContent`, перенос за судном и закрытие при исчезновении) — **без обращения к серверу**;
- в popup кнопка **«Подробнее»** — отдельный DOM-элемент с обработчиком (не `innerHTML`), поля popup — по-прежнему `textContent`; кнопка шлёт событие `vessel` (`data-message` = MMSI строкой; форма приводит к числу — в контракте MMSI число);
- форма открывает `КарточкаСудна` (параметр `MMSI`) и **хранит ссылку на открытую карточку**. Повторное «Подробнее» по другому судну вызывает **экспортный метод открытой карточки** (например, `ПоказатьСудно(MMSI)`), а не новый `ОткрытьФорму`: при той же уникальности платформа покажет уже открытую форму и `ПриСозданииНаСервере` заново не выполнит. Данные — с сервера из последнего снимка `СнимкиAISV2` (позже — рейсы ЕДС по IMO);
- закрытие popup снимает выделение, как в V1; карточка от выделения не зависит.

### 9.8. Район V2

`ПолучениеДанныхAISV2.ПараметрыРайона()` — **не копия V1**: в V1 `minZoom` 8 и `maxBounds` `[128.5, 40.5, 135.5, 45.5]`; на zoom 8 окно ≈ 1400 px показывает ≈ 3,9° долготы при bbox кеша 0,8° — почти весь кадр был бы без тайлов.

- `bbox` — bbox набора и запроса судов: `[131.55, 42.80, 132.35, 43.25]` (≈ 65 × 50 км); `КартографическиеДанныеV2.ПараметрыНабора()` берёт его отсюда;
- `center` `[131.90, 43.08]`, `zoom` 11, `maxZoom` 18, `terminal` `[131.8799, 43.0897]` — как в V1 (центр и ВМКТ внутри кеша; `maxZoom` 18 — растягивание поверх `maxzoom` 14 источника);
- **`minZoom` 11**: поле карты у пользователя шириной 2269 px (диагностика 17.10.2026) на zoom 11 охватывает ≈ 0,78° долготы — почти весь bbox; ниже 11 опускать нельзя;
- `maxBounds` — bbox набора с запасом **0,05° по долготе и 0,03° по широте** с каждой стороны: `[131.50, 42.77, 132.40, 43.28]`. MapLibre ограничивает видимую область, а не центр: если окно шире `maxBounds`, библиотека сама поднимает зум. На 2269 px zoom 11 даёт 0,78° при bbox 0,80° — впритык; на 2560 px нужно 0,88°, поэтому запас не меньше 0,04° с каждой стороны. Тайлы запаса в набор не входят — там цвет фона (`bounds` TileJSON, п. 9.4).

## 10. Диагностика V2

Копия диагностики V1 (загрузка библиотеки, WebGL1 обязательно, WebGL2/ES2020 справочно, API, worker, сеть, пробный запуск) плюс:

- **мост большими строками**: форма передаёт строки 0,5 / 1 / 2 / 4 МБ командой и читает ответ (больше 4 МБ — только если меньшие прошли); в отчёте — время и успех по размерам;
- **base64**: `atob` 10 МБ и перевод в `ArrayBuffer` — время;
- **тестовый набор качается с клиента**: форма диагностики `ПолучитьАсинх` загружает 8–10 ресурсов (стиль Positron, TileJSON, тайлы z14 вокруг ВМКТ, `Noto Sans Regular/1024-1279.pbf`, спрайт), упаковывает **тем же кодом, что загрузчик** (base64 без переводов строк, `ЗаписьJSON`), и передаёт через мост. Один прогон проверяет клиентский HTTPS (OpenSSL, прокси клиента), отсутствие переводов строк в base64, размер строки в мосте, `atob` и `addProtocol` в V8WebKit; общий код упаковки пишется один раз. Ничего не вшивается в макет;
- **addProtocol**: пробная карта из этого тестового набора (ключи по правилу п. 7.1, TileJSON с `bounds` и `minzoom`) — без сети; обработчик возвращает `{cancel}`;
- **хранилище**: доступность `localStorage`, `IndexedDB`; запись маркера и проверка при следующем открытии диагностики (постоянство между сеансами).

## 12. Порядок работ

1. **checks** — шаг 0 без 1С (раздел 4.1) — выполнено 17.10.2026.
2. **rename-v1** — перед переименованием закоммитить текущее состояние (переименование переносит каталоги объектов, в том числе `Schedule.schedule` регламента); раздел 5; проверить текст запроса `ПоследнийСнимок` и `ОткрытьФорму`; `get_project_errors`; открыть форму V1 в базе.
3. **metadata-v2** — раздел 6.
4. **diag-v2** — форма `Диагностика` V2 (раздел 10) и **прогон в тонком клиенте** локально и через RDP; результаты в план: размер пакета, порог моста, постоянство хранилища, `addProtocol` в V8WebKit. При расхождении с разделами 7–9 — сначала правка плана.
5. **loader** — `КартографическиеДанныеV2` и форма `ЗагрузкаКарты`; загрузить набор в тестовую базу.
6. **cache-transfer** — открытие формы, пакеты, `addCachePackage`, индикатор.
7. **viewer-v2** — протокол, переписывание адресов, запуск карты, морская обстановка.
8. **vessels-v2** — снимки, регламент, опрос, popup, `КарточкаСудна`.
9. **docs** — AGENTS.md, план.
10. **check** — проверки и приёмка (раздел 13).

## 13. Критерии приёмки

- Объекты этапа 1 называются с суффиксом V1 (кроме общих `ТокенOpenWaters`, подсистемы и ролей), `get_project_errors` без ошибок (информационные `right-*` о правах корня конфигурации остаются, как в AGENTS.md); карта V1 в подсистеме открывается и получает свежие снимки своим регламентом.
- Администратор в тонком клиенте загружает набор: прогресс, итог (ресурсы, объём, время), набор становится активным. Повторная загрузка заменяет набор; прерванная загрузка оставляет прежний активным, в регистрах не остаётся пакетов `failed`; брошенная загрузка (закрытый клиент) убирается при следующем `НачатьНабор`; закрыть форму загрузки во время работы можно только через отмену.
- Пользователь без права изменения не видит команды загрузки; серверная запись набора им отклоняется.
- Форма карты V2 при открытии показывает индикатор и через время, согласованное по шагу 0, рисует подложку Positron с русскими подписями, значки Liberty, морскую обстановку, суда.
- **Клиент без доступа в интернет** (сетевой кабель, блокировка доменов или правило файрвола): карта V2 работает целиком — подложка, подписи, смена стилей, морская обстановка, суда. В сетевой активности HTML-поля (или в журнале обработчика протокола в эмуляции) нет ни одного запроса к `openfreemap`, `openseamap`, Overpass.
- После загрузки карты серверные вызовы формы — только опрос позиций (раз в 30 с) и `КарточкаСудна` (проверка по замеру производительности 1С или журналу вызовов). Клик по судну и popup к серверу не обращаются.
- «Подробнее» в popup открывает карточку с данными с сервера; «Подробнее» по другому судну меняет данные в той же карточке.
- Без активного набора — понятное сообщение и суда на пустом фоне.
- Позиции судов обновляются регламентом V2 и доходят до карты к следующему такту опроса.

## 14. Риски

| Риск | Признак | Что делаем |
|---|---|---|
| Строки пакетов слишком велики для моста 1С ↔ V8WebKit | Шаг 0: ошибки или секунды на 2–4 МБ | Уменьшить пакет (0,5–1 МБ), больше команд |
| `addProtocol` ведёт себя в V8WebKit иначе, чем в эмуляции | Диагностика V2: пробная карта без сети не рисуется | Запасной путь — `transformRequest` + Blob URL из кеша (`URL.createObjectURL`), проверить в эмуляции |
| Источник всё равно отдаёт gzip на `Accept-Encoding: identity` | Первые байты `1f 8b` (загрузчик проверяет) | 17.10.2026 все источники отвечали без сжатия (п. 4.1). Если изменится — распаковка в JS (небольшая ES5-библиотека inflate) при упаковке или на клиенте карты |
| Набор большой, открытие формы долгое | Время переноса > 10 с | Уменьшить bbox или верхний масштаб; постоянное хранилище страницы (п. 9.6); позже — HTTP-сервис (вариант 1 из разговора 17.10.2026) |
| Overpass недоступен или ограничивает | Ошибки 429/5xx при загрузке (17.10.2026 пять из шести адресов отвечали 5xx) | Список адресов в параметрах, первым `z.overpass-api.de`; повтор; при неудаче — набор без морской обстановки с предупреждением, морскую обстановку можно догрузить позже |
| Изменение схемы или адресов OpenFreeMap | Ошибки загрузки | Только загрузчик; карта работает на прежнем активном наборе |

## 15. Решения по открытым вопросам (ревью 18.10.2026)

1. **Константа токена** — одна общая `ТокенOpenWaters`, без суффикса.
2. **Клик по судну** — popup в JS без сервера и кнопка «Подробнее» к форме `КарточкаСудна`.
3. **Район кеша** — акватория подходов, ≈ 65 × 50 км (131.55–132.35° в. д., 42.80–43.25° с. ш.). Отклонены: ближняя зона ≈ 33 × 28 км (≈ 10 МБ), весь район карты V1 ≈ 163 × 111 км (≈ 26 МБ).
4. **Стили** — пока Positron и Liberty; позже свой, ещё более упрощённый стиль (вне этапа 2).
5. **Карта V1** — остаётся в подсистеме; поэтому её регламент не выключается (п. 3).

- **metadata-v2**: регистры `СнимкиAISV2`, `НаборыКартыV2`, `ПакетыКартыV2`; общие модули `ПолучениеДанныхAISV2`, `КартографическиеДанныеV2` (сервер), `КартографическиеДанныеКлиентV2`, `МостКартыКлиентV2` (клиент); регламент `ПолучитьСудаAISV2` (раз в 5 минут); обработка `КартаПодходаСудовV2` с формами `Форма`, `КарточкаСудна`, `ЗагрузкаКарты`, `Диагностика`; права роли `Пользователь`; тестовая база обновлена.
- **Отклонения от разделов 7–10**, внесены при реализации:
  - общий код кеша и протокола `harbor://` вынесен в макет `КешКартыJS` (`window.harborCache`); его подключают и карта, и диагностика (плейсхолдер `/*@@CACHE_JS@@*/`), чтобы не дублировать раскладку пакетов, переписывание стиля и обработчик;
  - `КартографическиеДанныеV2.ОстальныеРесурсы(ТекстыНачальныхРесурсов, Параметры)` принимает соответствие «ключ → текст»: формы не знают, какой ключ — стиль, а какой — TileJSON;
  - в описании ресурса есть `ПропуститьПриОшибке` (только у Overpass): ошибка морской обстановки — пропуск с предупреждением, а не отказ загрузки (раздел 14);
  - страница шлёт `ready` после `window.load`; если событие до 1С не дошло, такт опроса формы спрашивает страницу командой `status` (ответ тот же: `<набор>|<пакетов>`);
  - из стиля удаляются все источники, кроме `openmaptiles` (не только `ne2_shaded`) — гарантия, что стиль не ходит в сеть;
  - пакеты пишутся `ЗаписьJSON` без переносов строк (`ПереносСтрокJSON.Нет`).
- **Эмуляция в Edge** (headless, без WebGL2, `fetch`, `ResizeObserver`, `createImageBitmap`; драйвер вместо 1С по контракту `МостКартыКлиентV2`): набор 157 ресурсов (z11–12 по району, z13–14 у ВМКТ), 5 пакетов, 7 МБ; `ready` до карты, индикатор 0–100 %, повтор пакета не задваивается, чужой пакет отклоняется; после `startMap` — Positron с русскими подписями, морская обстановка (137 объектов в кадре), суда; промахов кеша 0, **внешних запросов 0**; popup и «Подробнее» → событие `vessel`; Liberty со значками спрайта; без набора — сообщение и суда на пустом фоне. Диагностика: эхо 0,5–4 МБ, base64 10 МБ за 22 мс, пробная карта через `harbor://` без промахов.

Первые прогоны в тонком клиенте (18.10.2026):

- Модуль `ПолучениеДанныхAISV2` не компилировался: в начале файла было два BOM (исходник сгенерирован из модуля V1 вместе с BOM, `write_module_source` добавил свой). Исправлено; источники для `write_module_source` — без BOM.
- Полный набор загружен, карта V2 рисуется — пакеты по 1,5 МБ мост принимает.
- Диагностика V2 зависала без отчёта: `typeof window.localStorage` в HTML-поле бросает `SecurityError` (у документа нет обычного источника), исключение обрывало сбор сведений. Проверки обёрнуты в `try` по одной.
- **Диагностика V2, локально (V8WebKit 605.1, WebGL1 через ANGLE D3D9Ex, devicePixelRatio 1,25):**
  - мост 1С → страница: 0,5 / 1 / 2 / 4 МБ приняты целиком за 10 / 13 / 23 / 30 мс — порог моста выше 4 МБ, пакет 1,5 МБ с большим запасом (можно поднять до 3–4 МБ после прогона через RDP);
  - `atob` 10 МБ → `ArrayBuffer` за 28 мс; переводов строк в base64 и в тексте пакета нет;
  - тестовый набор с клиента: 13 ресурсов, 914 КБ за 2,7 с (HTTPS из тонкого клиента работает, gzip не пришёл); пакет 1,25 млн символов передан за 19 мс;
  - пробная карта через `harbor://` без сети — 2,5 с, 11 запросов; два промаха `0-255.pbf` — в тестовом наборе был только кириллический диапазон, добавлен `0-255`;
  - **хранилища нет**: `localStorage` — `SecurityError`, IndexedDB — «IDBFactory.open() called in an invalid security context». П. 9.6 — без оптимизации: каждое открытие формы переносит набор заново.

- 18.10.2026 суда пропали из выдачи Open Waters: по акватории подходов одно судно суточной давности (17.10 — 118 судов, позиции 10–16.10). Решение пользователя: ответ API, в котором меньше 20 судов, снимок V2 не перезаписывает (`МинимумСудовДляЗаписи()`); для показа добавлена команда формы карты «Загрузить снимок из файла» — сохранённый GeoJSON Open Waters через тот же адаптер, без порога.

- Морская обстановка (п. 9.5) дополнена значками, как у OpenSeaMap: viewer рисует их на canvas по требованию (`styleimagemissing`), без сети и без ресурсов в наборе. Имя значка `sm-<вид>-<форма>-<цвета>` вычисляется из тегов при разборе Overpass: якорь — якорная стоянка и место (места — с z13), синий якорь — гавань, «капля» огня цвета огня, буй по форме и полосам цветов, знак, затонувшее судно, «P» — лоцманы, «R» — радиостанция. У районов якорных стоянок, гаваней, маяков-зданий и затонувших судов значок ставится в центр. Кружки остаются у точек без значка.

- Третья подложка «Морская (минимальная)» (решение по п. 15.4): Positron, из которого при выдаче стиля остаётся 21 слой — фон, жилая застройка, вода, пирсы, главные дороги и мосты, железная дорога, названия акваторий и населённых пунктов, `label_other`. Список — `STYLE_VARIANTS` в `МакетJS`; набор и загрузчик не меняются. Подсчёт по тайлам района (z14): 7,2 тыс. объектов против 22,6 тыс. у Positron и 109 тыс. у Liberty (две трети у Liberty — иконки POI с z15).

- «Предупреждение безопасности… ПолеHTMLДокумента пытается открыть локальный файл blob:null/…» (платформа 8.3.27): спрайт декодируется страницей из `data:` (окна при смене подложки больше нет); остаётся одно окно при открытии — рабочие потоки MapLibre из `blob:`. Потоки из `data:` проверены диагностикой 18.10.2026: создаются, но молчат («нет ответа за 3 с»), пробная карта не загружается — перехватчик удалён. Снять оставшееся окно можно только настройкой клиента (`DisableUnsafeActionProtection` в `conf.cfg`) или флажком пользователя «Защита от опасных действий».

Осталось (нужен тонкий клиент 1С):

- **diag-v2**: прогон формы «Диагностика» V2 локально и через RDP — порог моста, переводы строк, `atob`, `addProtocol` в V8WebKit, постоянство хранилища; по результатам — `packageSize` в `ПараметрыНабора()` и п. 9.6.
- **loader**: загрузить полный набор в тестовую базу формой «Загрузка картографических данных».
- **check**: приёмка по разделу 13, в том числе с отключённым интернетом у клиента.
